# Attorney Timesheet

A private, browser-only weekly time and travel report. It has no server and sends no data anywhere.

## Use it

Open `index.html` in Chrome. Enter the week's information and use **Print / Save PDF**. In Chrome's print dialog, choose **Save as PDF**, set layout to **Landscape**, and enable **Background graphics** if Chrome does not do so automatically.

Entries are automatically retained in that browser using local storage. Use **Clear week** when the next report begins.

## Put it on GitHub Pages

1. Add this folder's files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch and root folder, then save.
4. Bookmark the Pages link in Chrome.

Because this is a static application, it works on Windows, macOS, and phones. Data remains on each device; it does not sync between browsers.
